# Notion MCP

The official Notion MCP server. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@notionhq/notion-mcp-server

Installs from the Camillia hub as `notion-mcp-8cd0aa`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
